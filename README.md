# OSK 双联动引擎 · 招商落地页

BSC 主网（ChainID 56）挖矿生态招商页。上线地址：https://ladchen.github.io/osk-club/

## 页面机制
- 六大挖法：农场（13 档利率 0.5–2.5%/天）、OSK/FIST 质押（10 天 +7%）、FISTDAO 空投质押（10.5%/7 天）、节点认购（1/2/5 BNB）、节点分红双系统
- 资金走账全景动画：入金 10/20/70 分配、税收流转、静态收益 30% 四路加权、FISTDAO 五跳换币
- TP 钱包（BSC）「登陆绑定你的地址」：一次签名 + 一次 0.005 BNB 支付，完成后显示已绑定地址（一键复制）
- 顶栏「推广页链接」/「复制推广链接」：一键复制 https://ladchen.github.io/osk-club/?ref=你的地址 发给朋友，对方页面即显示你的推荐地址
- 纯 CSS/SVG 动画 + 内联 JS（零外部依赖），桌面/移动双版本自适应

## 配置
- 收款地址（网页制作费）：`index.html` 内联脚本顶部 `FEE_RECEIVER` 常量
- 费率：`FEE_BNB` 常量（默认 0.005）
